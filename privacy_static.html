Privacy Policy

Last updated: August 2026

TradeGate collects zero user data. All information is stored locally on your device and never transmitted to any server.

1. Extension Purpose (Single Purpose Justification)

TradeGate is a local-first trading journal, pre-trade discipline gate, and strategy-isolated performance analytics terminal that operates entirely within your browser as a Chrome side panel extension.

The extension's single purpose is to help traders enforce pre-trade checklist discipline, calculate position sizing based on risk parameters, log trade entries with execution quality tags, and analyze trading performance across isolated strategy profiles — all without requiring any account, login, or internet connection for core functionality.

2. Data Storage

TradeGate stores all data exclusively in chrome.storage.local — the browser's built-in local storage API for extensions. This means:

  • ✓ Your trading data never leaves your device
  • ✓ There are no remote servers, databases, or cloud storage
  • ✓ There is no account creation, login, or authentication
  • ✓ Data persists only until you manually delete it or uninstall the extension

Stored data includes: Strategy profiles (name, rules, risk limits, base currency), trade log entries (symbol, direction, entry/exit prices, notes, screenshots), settings preferences (theme, trading sessions), and backup export files you explicitly create.

3. Data Collection

TradeGate does not collect any data. Specifically:

  • ✗ No analytics or telemetry of any kind
  • ✗ No user tracking, fingerprinting, or identification
  • ✗ No cookies or cross-site tracking
  • ✗ No personal information collection (name, email, IP, etc.)
  • ✗ No trading data, positions, or financial information is ever transmitted

4. Chrome Permissions Explained

TradeGate requests only the minimum permissions required for its core functionality. Below is a transparent explanation of every permission used:

storage

Provides access to chrome.storage.local to persist your strategy profiles, trade log entries, theme preferences, trading session configurations, and draft trade state across browser sessions. All data remains on your device.

unlimitedStorage

Removes the default 5MB storage quota for chrome.storage.local, allowing your trade history, screenshots, and analytics data to grow without hitting storage limits. No data is sent elsewhere.

sidePanel

Enables TradeGate to render as a Chrome Side Panel — a persistent overlay alongside your active tab. This is the extension's primary UI surface, allowing you to journal trades while viewing charts.

activeTab

Required for side panel activation on the current tab context. TradeGate does not read, modify, or interact with the content of any web page you visit.

scripting

Enables side panel injection into the active tab context. This permission is used solely for the side panel rendering mechanism and does not execute any scripts on web pages.

5. Host Permissions

TradeGate requests access to two external domains for asset display purposes only:

https://s3-symbol-logo.tradingview.com/*

Fetches exchange and asset logo images (SVG) for visual display in the ticker search and trade log. Only image files are downloaded — no user data is sent to this endpoint.

https://symbol-search.tradingview.com/*

Provides ticker symbol autocomplete search functionality. Search queries contain only the partial ticker text you type (e.g., "BTC") — no personal, financial, or identifying data is included in these requests.

6. Third-Party Services

TradeGate's only external network requests are to TradingView's public CDN for logo images and ticker symbol search. These requests:

  • • Contain no user-identifying information
  • • Do not transmit any trading data, positions, or financial information
  • • Are limited to fetching publicly available static assets (SVG images, search results)

No other third-party services, SDKs, analytics platforms, crash reporters, or ad networks are used.

7. Data Retention & Deletion

All data is stored locally and fully under your control:

  • • Delete individual items: Remove strategies, trades, or settings from within the extension's Settings Hub
  • • Delete all data: Uninstall the extension to remove all stored data
  • • Export before deletion: Use the built-in Backup & Export feature to download a JSON file of your data before deleting

8. GDPR, CCPA & International Privacy Compliance

Because TradeGate does not collect, process, store, or transmit any personal data to any server, the following privacy regulations are satisfied by design:

  • • GDPR (EU): No personal data processing occurs. No data controller or processor role applies.
  • • CCPA (California): No personal information is sold, shared, or disclosed to third parties.
  • • Data Subject Requests: Not applicable — no personal data is collected that would require access, correction, or deletion requests.

9. Children's Privacy

TradeGate is a trading journal tool intended for adult traders. The extension does not knowingly collect any information from children under 13. Since no data is collected from any user, this is satisfied by design.

10. Changes to This Policy

If this privacy policy is updated, changes will be reflected on this page with an updated "Last updated" date. Since TradeGate collects no data, changes to this policy are expected to be minimal and primarily for clarification purposes.

11. Contact
